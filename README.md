# java-lotto-precourse

#### 로또
<br>

### 1. 입력 기능
- 로또 구입 금액 입력
  - 사용자로부터 구입 금액을 입력받는다.
  - 금액을 1,000원 단위로 나누어 발행할 로또 개수를 계산한다.
- 당첨 번호 입력
  - 쉼표(,)로 구분된 6개의 숫자를 입력받는다.
- 보너스 번호 입력
  - 1개의 숫자를 입력받으며, 당첨 번호와 중복될 수 없다.

#### 🚫 예외 처리 상황 🚫
- 구입 금액 관련
  1. 숫자가 아닌 경우
  2. 1,000원 단위가 아닌 경우
  3. 0원 이하인 경우
  4. 입력이 비어 있는 경우
- 당첨 번호 관련
  1. 입력이 비어 있는 경우
  2. 개수가 6개가 아닌 경우
  3. 구분자가 쉼표(,)가 아닌 경우
  4. 숫자가 아닌 값이 포함된 경우
  5. 중복된 숫자가 포함된 경우
  6. 1~45 범위를 벗어난 경우
- 보너스 번호 관련
  1. 입력이 비어 있는 경우
  2. 숫자가 아닌 경우
  3. 1~45 범위를 벗어난 경우
  4. 당첨 번호와 중복되는 경우
  5. 여러 개 입력된 경우

### 2. 로또 발행 기능
- 구입 금액에 따라 발행할 로또 개수를 계산한다. `(amount / 1000)`
- 각 로또는 1~45 사이의 중복되지 않은 숫자 6개로 구성된다.
  - `Randoms.pickUniqueNumbersInRange(1, 45, 6)` 사용
- 발행된 로또 번호는 오름차순으로 정렬한다.

#### 🚫 예외 처리 상황 🚫
- 발행된 로또의 번호 개수가 6개가 아닌 경우
- 발행된 번호 중 중복이 있는 경우
- 발행된 번호가 1~45 범위를 벗어난 경우

### 3. 당첨 확인 기능
- 사용자가 구매한 모든 로또에 대해 당첨 번호와의 일치 개수를 확인한다.
- 보너스 번호 포함 여부에 따라 등수를 결정한다.

### 4. 수익률 계산 기능
- 총 당첨 금액을 합산한다.
- `수익률 = (총 당첨 금액 / 구입 금액) x 100`
- 소수점 둘째 자리에서 반올림한다.
